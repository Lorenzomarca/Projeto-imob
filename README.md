# 🏠 projeto-imob

Projeto desenvolvido para a **Feira de Ciências do SENAI**, com o objetivo de colocar à prova nossas capacidades técnicas e de trabalho em equipe.

---

## 📖 Sobre o projeto

O **projeto-imobiliaria** é uma interface web de uma imobiliária, desenvolvida **apenas com front-end** para fins de apresentação na feira. Não há back-end nem banco de dados: os dados exibidos são fictícios e servem para demonstrar o design e a navegação do sistema.

## 🎯 Objetivos

- Testar e desenvolver nossas habilidades técnicas
- Aplicar na prática os conhecimentos adquiridos no SENAI
- Trabalhar em equipe, organizando tarefas e dividindo responsabilidades
- Apresentar um projeto funcional na Feira de Ciências

## 🚀 Como executar

```bash
# 1. Clone o repositório
git clone https://github.com/Lorenzomarca/projeto-imob.git

# 2. Acesse a pasta do projeto
cd projeto-imob

# 3. Instale as dependências
npm install

# 4. Execute o projeto
npm run dev
```

Depois, abra o endereço exibido no terminal (geralmente `http://localhost:5173`) no navegador.
